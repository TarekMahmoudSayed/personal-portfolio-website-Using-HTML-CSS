01 About Me

I'm a Software Engineering student at the Faculty of Computers and Artificial Intelligence, Beni Suef University. I started with the fundamentals: problem solving, C++, memory management and pointers, then moved through Object-Oriented Programming and core data structures (Arrays, Linked Lists, Stacks, Queues, Trees, AVL Trees, Graphs, Heaps) with Big O analysis.

I'm currently transitioning into Backend development, learning C#, ASP.NET Core and SQL to build real Web APIs. I care about software design more than syntax — breaking a problem into small, reusable building blocks first, then assembling them into clean, maintainable classes. I try to apply Clean Code and Separation of Concerns in everything I build, keeping business logic independent from the interface layer.
