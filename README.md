# Tarek Mahmoud | Personal Portfolio

A personal portfolio website built with pure **HTML5** and **CSS3** — no frameworks — as
a hands-on project while learning web fundamentals before moving into **.NET Backend
Development**.

🔗 **Live Demo:** https://github.com/TarekMahmoudSayed/personal-portfolio-website-Using-HTML-CSS.git

## About

I'm a Software Engineering student at the Faculty of Computers and Artificial
Intelligence, Beni Suef University. This site is where I document my background,
skills, and projects as I transition from C++ and Data Structures into Backend
development with C#, ASP.NET Core, and SQL.

## Built With

- HTML5 (semantic structure)
- CSS3 (Flexbox, positioning, pseudo-classes, media queries — no frameworks)
- [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) & [Inter](https://fonts.google.com/specimen/Inter) via Google Fonts

## Features

- Fully responsive layout (mobile, tablet, desktop)
- Sticky navigation bar
- Dark, developer-inspired visual theme
- No JavaScript / no external CSS frameworks — built from scratch to practice core concepts

## Run Locally

Clone the repo and open `index.html` in your browser — no build step required.

```bash
git clone https://github.com/TarekMahmoudSayed/portfolio.git
cd portfolio
```

Then open `index.html` directly, or serve it with a simple local server (e.g. the
VS Code "Live Server" extension).
